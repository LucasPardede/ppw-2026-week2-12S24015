DelLib — Sistem Sirkulasi & Basis Data Perpustakaan

DelLib merupakan perancangan sistem informasi manajemen perpustakaan yang menitikberatkan pada keandalan skema basis data relasional ternormalisasi (Third Normal Form - 3NF) untuk katalog buku, riwayat sirkulasi, dan kalkulasi denda otomatis.

3NF
Normalisasi Skema Penuh
0%
Anomali Redundansi Data
15,000+
Data Koleksi Buku Terindeks
Keunggulan Teknis & Basis Data:
  • Integritas Relasional: Penerapan Foreign Key Constraints, Cascading Rules, dan Check Constraints pada PostgreSQL.
  • Stored Procedures & Triggers: Kalkulasi denda harian dan auto-update status buku saat pengembalian terlambat.
  • Indexing B-Tree Efisien: Optimasi kueri pencarian teks ISBN, pengarang, dan klasifikasi DDC buku.
  • Audit Logging: Pencatatan riwayat transaksi peminjaman untuk akuntabilitas inventaris pustakawan.
Instrumen Teknologi:
React.js Node.js Express PostgreSQL Prisma ORM ERD Normalization

SecureAudit — Web Vulnerability Tester

SecureAudit adalah tool edukasi dan simulasi pengujian celah keamanan aplikasi web untuk standar OWASP Top 10, difokuskan pada sanitasi input form dan analisis header HTTP.

Lingkup Pengujian Keamanan:
  • SQL Injection Vector Scanner: Deteksi karakter berbahaya pada parameter form input.
  • Cross-Site Scripting (XSS) Sanitizer: Evaluasi efektivitas DOMPurify dan escaping entitas HTML.
  • HTTP Security Headers Checker: Verifikasi Content-Security-Policy, X-Frame-Options, dan HSTS.
Instrumen Teknologi:
Node.js Express OWASP Standard Security Headers
